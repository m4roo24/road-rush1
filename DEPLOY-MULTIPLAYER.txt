ROAD RUSH — VERCEL FRONTEND + CLOUDFLARE MULTIPLAYER

The game frontend can stay on Vercel. The real-time multiplayer server is a Cloudflare Worker using a Durable Object room. No Render service is needed.

FILES
- cloudflare-worker.js: Worker and Durable Object multiplayer room
- wrangler.jsonc: Durable Object binding and migration configuration
- index.html: native WebSocket client

DEPLOY THE CLOUDFLARE MULTIPLAYER WORKER
1. Keep these files in the GitHub repository.
2. In a terminal with Node.js installed, open the repository root.
3. Run:
   npm install --save-dev wrangler
   npx wrangler login
   npx wrangler deploy
4. If Cloudflare asks you to confirm the Durable Object migration/binding, use the configuration in wrangler.jsonc.
5. Copy the deployed Worker URL. It will look like:
   https://road-rush-multiplayer.YOUR-SUBDOMAIN.workers.dev
6. Open https://YOUR-WORKER-URL/health and confirm it returns JSON with "ok": true.

If you already deploy this project with Wrangler, use the existing Cloudflare workflow and make sure wrangler.jsonc is at the project root.

PLAY
1. Open ROAD RUSH > Race friends.
2. Paste the Cloudflare Worker URL into Multiplayer Server URL.
3. Leave the room code empty and tap Create / Join Race.
4. Share the generated room code with your friend.
5. Your friend enters the same Worker URL and room code.

RACE REWARDS
The race waits for two connected players. The winner gets a fixed 100 in-game coin bonus. The losing player keeps their own coin balance. A draw awards no bonus. These are game rewards, not real money.

IMPORTANT
The Cloudflare Worker must be deployed separately from the static Vercel frontend. This is a basic multiplayer prototype; do not treat client-reported gameplay or coin values as cheat-proof competitive records.
