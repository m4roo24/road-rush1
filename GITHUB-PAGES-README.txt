ROAD RUSH — PC + Mobile

GitHub Pages: upload index.html, manifest.webmanifest, sw.js, and icon files from this folder to the repository ROOT. The server-project folder is for optional Node.js hosting; GitHub Pages cannot run server.js.

Controls: Arrow Left/Right or A/D to steer. Esc or P pauses/resumes. Enter restarts after a crash. Menus work with mouse clicks. Mobile uses tap/swipe or on-screen steering buttons.

Note: online accounts/cloud saves require deploying server-project to a Node.js host; GitHub Pages alone supports static game files only.
